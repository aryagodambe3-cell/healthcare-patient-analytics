# Healthcare Patient Analytics

## 📌 Project Overview

This project analyzes healthcare patient data to identify patterns related to patient demographics, hospital visits, and readmission outcomes.

The analysis uses Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook to clean, explore, and visualize healthcare data.

## 🎯 Objectives

- Analyze patient demographics
- Study patient distribution by gender and age
- Analyze hospital readmission patterns
- Clean and preprocess healthcare data
- Generate meaningful visualizations
- Calculate important healthcare metrics

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub
